# Historique des versions

## 1.0.0 — 2026-11-05 — Kit de livraison

- Galerie 3D complète : architecture (verrière, rampants à nervures, pilastres, corniches,
  soubassements, portes, chaises), vestibule et petite salle du fond, 30 œuvres d'exemple.
- Contenu externalisé dans `content/site.json` (+ schéma JSON) : textes, liens, thème, œuvres.
- Interface d'administration « Atelier » (`admin/`), utilisable sur téléphone : œuvres
  (image, peinture générée, affiche), liens et documents, ouverture directe au clic,
  placement sur plan déplaçable, textes, ambiances de couleurs, liens du portfolio,
  brouillon automatique, aperçu, publication GitHub en un commit, export/import.
- Visuel « Affiche » pour présenter un document ou un lien.
- Thèmes de couleurs appliqués à la 3D (murs, moulures, bois, parquet, dorures) et à l'interface.
- Mobile : joystick, menu ☰, fiche plein écran, champ de vision adapté au portrait.
- Bibliothèques incluses dans `vendor/` (plus de dépendance CDN).
- Documentation : AI_CONTEXT, technique, guide du propriétaire, déploiement GitHub Pages.
- Outil `tools/check.mjs` ; scripts de lancement Mac / Windows.
